## 動作確認の手順（チェック用）

### A. サーバー起動

1. ターミナルで `npm run dev` を実行
2. ブラウザで `http://localhost:3000/login` を開く

### B. ログイン

1. `/login` でボタン **「Googleで続ける」** をクリック
2. Google画面で許可（表示される場合）→ アプリに戻る

### C. 認証ガード

1. 未ログイン状態で `http://localhost:3000/profile` を開く
2. `/login` に遷移し、URLに **`?next=/profile`** が付くことを確認

### D. 画面切替（ボトムナビ）

1. ボトムナビのボタン **「ホーム」** をクリック → `/`
2. ボトムナビのボタン **「AI」** をクリック → `/compose`
3. ボトムナビのボタン **「プロフィール」** をクリック → `/profile`

### E. AIチャット機能

1. `/compose` に移動し、AIタブを選択
2. 麹の種類を選択（例: 中華麹）
3. チャットをスキップして直接チャットを開始
4. AIの返答とチップが正しく表示されることを確認
5. チップをクリックして会話を進める
6. 3回目の会話後に「レシピを作成する」ボタンが表示されることを確認
