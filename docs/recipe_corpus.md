## 1. 共通の傾向（文体・設計）

- **少ない材料・短い工程**（電子レンジ活用、下味→焼く/煮る、など）
- **最後にPOINT**（「塩気が足りない→こうじを少しずつ追加」等）
- 分量は **2人前中心**（1人前/2〜3人前/3〜4人前もあり）

## 2. たまねぎこうじ（TAMANEGI）

### 2-1. レタスサラダ（2人前）

- **材料**: レタス 半玉 / きゅうり 1本 / ツナ缶 1缶 / マヨネーズ 大2 / たまねぎこうじ 大1 / コショウ お好みで
- **作り方**:
  - レタスはちぎり、きゅうりは薄切り
  - 材料をボウルで混ぜる
  - コショウで仕上げ
- **POINT**: 塩気が足りない場合は、たまねぎこうじを少しずつ追加

### 2-2. ネギ塩豚ロース（2人前）

- **材料（不明あり）**: 豚ロース 200g / 長ねぎ 1/2本 / たまねぎこうじ 大1/2 / ごま油 大1 / コショウ 少々 / （レモン: 任意）
- **作り方（要約）**:
  - 豚ロースに たまねぎこうじ＋コショウで下味
  - ねぎみじん切り＋ごま油＋たまねぎこうじでネギ塩ダレ
  - 焼いてタレを絡める（レモン相性良）

### 2-3. ブリの唐揚げ（2人前）

- **材料**: ブリ 3切れ / たまねぎこうじ 大1.5 / 片栗粉 適量
- **作り方**:
  - ぶつ切りにしたブリにたまねぎこうじを混ぜ、20〜30分寝かせる（時間あればもっとOK）
  - 片栗粉をまぶし、カラッと揚げる

### 2-4. 和風おろしハンバーグ（2人前）

- **材料**: ひき肉 200g / 玉ねぎ 1/2個 / 絹豆腐 150g / たまねぎこうじ 大2
- **和風ソース**: 大根（5cmくらい・お好み）/ 醤油 大1.5 / 酒 大1.5 / みりん 大1.5 / 酢 大1/2 / 砂糖 小1/2
- **作り方（要約）**:
  - 豆腐をレンチン→水切り
  - 具材を混ぜて焼き、蓋して蒸し焼き
  - ソースを温めてかける

### 2-5. 定番おかず（簡単おかず4選）

- **野菜炒め**: 味付けはたまねぎこうじのみ（目安: 大1〜）。野菜量で調整。塩コショウ/醤油を入れるタイミングで混ぜると良い
- **とんかつ**: 肉1枚に たまねぎこうじ大1 → 15〜20分置く → 衣 → 揚げる（しっとりジューシー）
- **ホイル焼き**: 魚1切れに たまねぎこうじ大1 を塗り、野菜と蒸し焼き（ふっくら＋甘み）
- **たまご焼き**: 卵2個に たまねぎこうじ大1（小さめ卵は3個）。甘めなら砂糖追加。巻きにくい時は水溶き片栗粉(1:1)

### 2-6. 手作りドレッシングでやみつきブロッコリー（2〜3人前）

- **材料（読み取り範囲）**: ブロッコリー 1/2株 / ゆで卵 2個 / ツナ缶 1缶 / たまねぎこうじ 大1〜1.5 / 酢 大1 / 砂糖 大1 / オリーブオイル 大1
- **作り方（要約）**:
  - ブロッコリーを小房に分けて茹で、水気をしっかり切る
  - ゆで卵は食べやすく切る
  - 調味料を混ぜて和える（崩れないようにやさしく）

### 2-7. ルウなし本格キーマカレー（3〜4人前）

- **材料（読み取り範囲）**: ひき肉 200g / 玉ねぎ 1個 / セロリ 1/2本 / にんじん 1/2本 / たまねぎこうじ 大2 / ケチャップ 大2 / カレー粉 大2 / 水 200cc

- **注意点**: たまねぎこうじは**必ず炊飯時に入れる**（炊飯後に入れると酵素ででんぷんが分解され、水っぽくなりやすい）

  - ほうれん草は水に10分さらして軽く茹で、5cmに切る。ベーコンも食べやすく切る
  - 材料をボウルでよく混ぜる
  - 180℃に予熱したオーブンで20分焼く（固さを見て追加加熱）
- **補足**: 具材はアレンジ可だが、水分の多い野菜は避ける（不明あり）

### 4-9. ブロッコリー&ベーコン 5分で絶品スープ（2〜3人前）

- **材料（読み取り範囲）**: ブロッコリー 1/2株 / ベーコン 4枚 / にんにく 1片 / オリーブオイル 小1 / コンソメこうじ 大2
- **作り方（要約）**:
  - にんにく＋ベーコンを炒め、残りの材料を入れて蓋して煮込む（詳細な水量は不明）
  - ブロッコリーがくたっとしたら出来上がり

### 4-10. エビのマリネ（2〜3人前）

- **材料（読み取り範囲）**: にんじん 1本 / きゅうり 1本 / 玉ねぎ 1/2個 / ボイルえび お好みで / オリーブオイル 大2 / お酢 大1 / 砂糖 小1 / コンソメ麹 大1/2
- **作り方（要約）**:
  - 野菜は千切りにして塩（少量）で数分置き、水気を切る（にんじん/玉ねぎは不明あり）
  - ボウルで調味料を混ぜ、野菜＋えびを加えて和える
  - 冷蔵庫で冷やして完成

### 4-11. チューリップ揚げ（2〜3人前）

- **材料（読み取り範囲）**: 手羽元 8本 / コンソメ麹 大2 / ナツメグ（あれば）小1/4 / ブラックペッパー 少々 / 片栗粉 適量
- **作り方（要約）**:
  - 手羽元の下部分に一周切り込み→骨に沿って肉を上へ持ち上げる（チューリップ状）
  - 片栗粉以外をボウルで混ぜ、冷蔵庫で30分〜1時間漬ける（時間あれば一晩でも良い旨）
  - 片栗粉をまぶして揚げる（上部分は火が通りにくいので170℃程度でじっくり）

### 4-12. ほっこり優しい 即席たまごスープ（2〜3人前）

- **材料（読み取り範囲）**: たまご 2個 / えのき 1/2袋 / コンソメこうじ 大3 / 水 600cc
- **作り方（要約）**:
  - 鍋で水を沸騰させ、えのきを加え煮立てる
  - コンソメこうじを加え少し煮込んだら、溶き卵を回し入れて完成

### 4-13. これ、とまらん 揚げない黄金ポテト

- **材料（読み取り範囲）**: じゃがいも 中3〜4個 / コンソメこうじ 大1 / オリーブオイル 大1 / （お好みでスパイス）
- **作り方（要約）**:
  - じゃがいもは皮付きのままくし切り（水で洗う）
  - コンソメこうじとオリーブオイルを加えてよく混ぜる
  - 200℃に予熱したオーブンで20分焼く（焼き色がつくまで）
- **補足**: 蒸し焼き状態になるのでホクホク。水にさらさないほうがホクホクだが、カリッとさせたい場合は水にさらして水分を拭く。

### 4-14. 絶品アボカドトースト

- **材料（読み取り範囲）**: アボカド 1個 / マヨネーズ 大1 / コンソメこうじ 小1
- **作り方（要約）**:
  - アボカドを潰し、マヨネーズとコンソメこうじを混ぜる
  - トーストに乗せて召し上がれ（ゆで卵スライスのせ等のアレンジあり）
- **補足**: サンドイッチや生野菜との相性も抜群

### 4-15. コラボメニュー例（参考）

- **オム納豆コンソメソース**: とろとろオムレツにコンソメ麹を使ったソース
- **ポルチーニとマッシュルームのポタージュ**: コンソメこうじ使用（詳細レシピなし）
- **海鮮居酒屋コラボ**: シーフードパスタ、極上鶏ハム、中華ディップ、アヒージョなど（こうじ活用例として）

### 4-16. 超濃厚かぼちゃポタージュ（ママも嬉しい美容スープ）

- **材料（読み取り範囲）**: かぼちゃ 1/4個 / 玉ねぎ 1/2個 / コンソメこうじ 大1 / バター 10g / 水 50cc（野菜を煮る用） / 牛乳 300cc
- **作り方（要約）**:
  - スライス玉ねぎと小さく切ったかぼちゃをバターで炒める（しんなりするまで）
  - 水50ccとコンソメこうじを入れ、弱火で柔らかくなるまで蒸し焼き
  - ブレンダーで撹拌して滑らかにする
  - 牛乳を加えてとろみがつくまで少し煮込む
- **アレンジ**: ブラックペッパーやイタリアンハーブをアクセントに

### 4-17. 海老のコンソメ炒め（お弁当にも）

- **材料（読み取り範囲）**: 海老（殻むき） / 片栗粉 / コンソメこうじ / オリーブオイル / 酒（下味用） / （玉ねぎみじん切り: アレンジ）
- **作り方（要約）**:
  - 海老に酒とコンソメこうじで下味をつけ、片栗粉をまぶす
  - オリーブオイルでこんがり炒める（玉ねぎみじん切りと一緒に炒めてもOK）
- **POINT**: 海老がぷりっぷりに仕上がる。冷めても美味しいのでお弁当に最適。

## 5. 注意点（麹×でんぷん質）

**でんぷん質（米・芋・小麦など）**は、麹の酵素ででんぷんが分解されやすく、**水っぽく/崩れやすく**なります。  
加熱せずに使う場合は組み合わせに注意。

- **例: おにぎり**: 混ぜて握るとポロポロ崩れやすく、時間が経つと海苔が剥がれやすい
- **例: ポテトサラダ**: そのまま混ぜるとドロドロに → 麹は一度加熱してから混ぜる
- **例: 春雨サラダ**: 時間が経つとベチャっと水っぽい → 春雨炒め等、火を通せば問題が出にくい
- **例: わかめご飯**: たまねぎこうじは炊飯時に入れる（炊飯後に混ぜると水っぽくなりやすい）

**まとめ**: これは添加物なしで酵素が生きている証拠。でんぷん食材は注意だが、**麹調味料をしっかり加熱して使えばOK**。
