## 📄 Step 1: GitHubリポジトリ作成

ソースコードを管理する場所を作成します。

### お客様にご依頼すること

#### 1-1. GitHubアカウント作成

1. https://github.com/ にアクセス
2. 画面右上の「**Sign up**」ボタンをクリック
3. 以下を入力：
   - **Email address**: お客様のメールアドレス
   - **Password**: 強力なパスワード
   - **Username**: 任意のユーザー名（例: `ogawa-koji-recipe`）
4. メール認証を完了

#### 1-2. リポジトリ作成

1. GitHubにログイン
2. 画面右上の「**+**」→「**New repository**」をクリック
3. 以下を入力：
   - **Repository name**: `koji-recipe-app`（任意の名前でも可）
   - **Description**: `麹レシピWebアプリケーション`
   - **Visibility**: 
     - ✅ **Private**（推奨） - 他者から見えないようにする
     - ⚠️ Public - 誰でも閲覧可能（非推奨）
   - **Initialize this repository with**: チェック不要（空のままで作成）
4. 「**Create repository**」をクリック

#### 1-3. コラボレーター追加

開発者（実装担当者）をコラボレーターとして追加：

1. 作成したリポジトリのページで「**Settings**」タブをクリック
2. 左メニューの「**Collaborators**」をクリック
3. 「**Add people**」ボタンをクリック
4. **開発者のGitHubユーザー名またはメールアドレス**を入力
5. 「**Add [ユーザー名] to this repository**」をクリック
6. 招待が送信されます（開発者が承認する必要があります）

### 開発者への共有事項

以下の情報を開発者にお知らせください：

- ✅ **リポジトリURL**（例: `https://github.com/ogawa/koji-recipe-app`）

## 🗄️ Step 2: Supabaseプロジェクト作成

データベース（アプリのバックエンド）を作成します。

### お客様にご依頼すること

#### 2-1. Supabaseアカウント作成

1. https://supabase.com/ にアクセス
2. 画面中央の「**Start your project**」ボタンをクリック
3. 「**Continue with GitHub**」を選択（GitHubアカウントでサインアップ）
4. GitHubの認証画面で「**Authorize**」をクリック
5. メール認証を完了（確認メールが届きます）

#### 2-2. Organization作成（初回のみ）

1. Supabaseダッシュボードが開いたら、Organization名を入力
   - 例: お客様の会社名または個人名（`Ogawa-Koji`など）
2. 「**Create organization**」をクリック

#### 2-3. プロジェクト作成

1. 「**New project**」ボタンをクリック
2. 以下を入力：
   - **Organization**: 上で作成したOrganizationを選択
   - **Name**: `koji-recipe-production`
   - **Database Password**: 
     - 「**Generate a password**」ボタンをクリックして自動生成
     - ⚠️ **重要**: 生成されたパスワードを必ずコピーして安全な場所に保管してください（後で確認できません）
   - **Region**: `Northeast Asia (Tokyo)` を選択
   - **Pricing Plan**: `Free` を選択（初期は無料プランで問題ありません）
3. 「**Create new project**」をクリック
4. プロジェクト作成に1〜2分かかります（進行状況が表示されます）

#### 2-4. API認証情報の取得

プロジェクト作成完了後、以下の手順で認証情報を取得：

1. 左サイドバーの「**Settings**」（歯車アイコン）をクリック
2. 「**API**」タブをクリック
3. 以下の情報をコピーして控えてください：

   **【重要】以下の2つの情報が必要です：**
   
   - **Project URL**:
     - 「Configuration」セクションの「URL」
     - 形式: `https://xxxxxxxxxxxxx.supabase.co`
     - → **コピーして安全な場所に保管**
   
   - **anon public key**:
     - 「Project API keys」セクションの「anon public」
     - 形式: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`（非常に長い文字列）
     - 右側の「**Copy**」ボタンでコピー
     - → **コピーして安全な場所に保管**

#### 2-5. コラボレーター追加

開発者をプロジェクトに招待：

1. 「**Settings**」→「**Team**」タブをクリック
2. 「**Invite member**」ボタンをクリック
3. **開発者のメールアドレス**を入力
4. **Role**: `Owner` または `Admin` を選択
5. 「**Send invitation**」をクリック

### 開発者への共有事項

以下の情報を**安全な方法**で開発者に共有してください：

- ✅ **Supabase Project URL**
- ✅ **Supabase anon public key**
- ✅ **Database Password**（パスワード管理ツールや暗号化メール推奨）

⚠️ **セキュリティ注意**: これらの情報は機密情報です。メール本文に直接記載せず、パスワード管理ツール（1Password、LastPass等）やセキュアなファイル共有サービスをご利用ください。

## 🔐 Step 3: Google Cloud設定（OAuth認証用）

Googleログイン機能を使用するための設定です。

### お客様にご依頼すること

#### 3-1. Google Cloudプロジェクト作成

1. https://console.cloud.google.com/ にアクセス
2. Googleアカウントでログイン
3. 画面左上の「**プロジェクト選択**」ドロップダウンをクリック
4. 表示されたモーダルで「**新しいプロジェクト**」をクリック
5. 以下を入力：
   - **プロジェクト名**: `koji-recipe-oauth`
   - **場所**: 「組織なし」のままでOK
6. 「**作成**」ボタンをクリック
7. プロジェクト作成完了後、**作成したプロジェクトを選択**してください

#### 3-2. OAuth同意画面の設定

1. 左メニューの「**APIとサービス**」→「**OAuth同意画面**」をクリック
2. **User Type**を選択：
   - ✅ **外部**（External）を選択
   - 「**作成**」ボタンをクリック
3. **OAuth同意画面**の設定：
   - **アプリ名**: `麹レシピアプリ`
   - **ユーザーサポートメール**: お客様のメールアドレスを選択
   - **アプリのロゴ**: （任意・スキップ可）
   - **アプリドメイン**: （任意・スキップ可）
   - **承認済みドメイン**: （後で設定するのでスキップ）
   - **デベロッパーの連絡先情報**: お客様のメールアドレスを入力
4. 「**保存して次へ**」ボタンを3回クリック（スコープ、テストユーザーはスキップ）
5. 最後に「**ダッシュボードに戻る**」をクリック

#### 3-3. OAuth認証情報の作成

1. 左メニューの「**認証情報**」をクリック
2. 上部の「**+認証情報を作成**」→「**OAuth クライアント ID**」を選択
3. 以下を選択・入力：
   - **アプリケーションの種類**: `ウェブアプリケーション`
   - **名前**: `koji-recipe-supabase`
   - **承認済みのJavaScript生成元**: （空欄のままでOK）
   - **承認済みのリダイレクト URI**:
     - 「**+ URIを追加**」ボタンをクリック
     - 以下を入力: `https://xxxxxxxxxxxxx.supabase.co/auth/v1/callback`
     - ⚠️ **重要**: `xxxxxxxxxxxxx`の部分は、Step 2-4で取得した**Supabase Project URL**に置き換えてください
     - 例: `https://cykogheprysvhimwlndm.supabase.co/auth/v1/callback`
4. 「**作成**」ボタンをクリック
5. **OAuth クライアントが作成されました**というモーダルが表示されます
6. 以下の情報をコピーして控えてください：

   **【重要】以下の2つの情報が必要です：**
   
   - **クライアントID**: 
     - 形式: `xxxxxxxxxxxxx.apps.googleusercontent.com`
     - → **コピーして保管**
   
   - **クライアントシークレット**: 
     - 形式: `GOCSPX-xxxxxxxxxxxxx`
     - → **コピーして保管**

7. 「**OK**」をクリックしてモーダルを閉じる

#### 3-4. SupabaseにGoogle OAuth情報を設定

1. **Supabaseダッシュボード**に戻る（https://supabase.com/dashboard）
2. 作成したプロジェクトを選択
3. 左サイドバーの「**Authentication**」をクリック
4. 「**Providers**」タブをクリック
5. プロバイダー一覧から「**Google**」を探してクリック
6. 以下を設定：
   - **Enable Google provider**: トグルを**オン**にする
   - **Client ID**: Step 3-3でコピーした**クライアントID**を貼り付け
   - **Client Secret**: Step 3-3でコピーした**クライアントシークレット**を貼り付け
7. 「**Save**」ボタンをクリック

### 開発者への共有事項

以下の情報を開発者に共有してください：

- ✅ **Google OAuth Client ID**
- ✅ **Google OAuth Client Secret**

## 🚀 Step 4: Vercelプロジェクト作成

Webアプリを公開するサーバー（ホスティング）の設定です。

### お客様にご依頼すること

#### 4-1. Vercelアカウント作成

1. https://vercel.com/ にアクセス
2. 画面右上の「**Sign Up**」ボタンをクリック
3. 「**Continue with GitHub**」を選択
4. GitHubの認証画面で「**Authorize Vercel**」をクリック
5. Vercelダッシュボードが開きます

#### 4-2. GitHubリポジトリと連携

1. Vercelダッシュボードで「**Add New...**」→「**Project**」をクリック
2. 「**Import Git Repository**」セクションが表示されます
3. Step 1で作成した**GitHubリポジトリ**を探して「**Import**」ボタンをクリック
   - ⚠️ リポジトリが表示されない場合:
     - 「**Adjust GitHub App Permissions**」をクリック
     - 該当のリポジトリへのアクセスを許可してください

#### 4-3. プロジェクト設定

「Configure Project」画面で以下を確認・設定：

- **Framework Preset**: `Next.js`（自動検出されます）
- **Root Directory**: `.`（そのまま変更不要）
- **Build Command**: `npm run build`（デフォルトのまま）
- **Output Directory**: `.next`（デフォルトのまま）
- **Install Command**: `npm install`（デフォルトのまま）

#### 4-4. 環境変数の設定

⚠️ **重要**: デプロイ前に環境変数を設定してください。

「**Environment Variables**」セクションを展開し、以下を追加：

| Name | Value | 備考 |
|------|-------|------|
| `NEXT_PUBLIC_SUPABASE_URL` | Step 2-4で取得した**Project URL** | `https://xxxxx.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Step 2-4で取得した**anon public key** | `eyJhbGci...` |
| `GEMINI_API_KEY` | （空欄または`dummy`） | 後で設定（初期は不要） |

**追加方法**:
1. 「**Name**」フィールドに変数名を入力（例: `NEXT_PUBLIC_SUPABASE_URL`）
2. 「**Value**」フィールドに値を貼り付け
3. 「**Add**」ボタンをクリック
4. 上記3つすべてを追加

#### 4-5. デプロイ実行

1. すべての設定を確認
2. 「**Deploy**」ボタンをクリック
3. デプロイが開始されます（通常3〜5分かかります）
4. 進行状況が表示されます：
   - Building... (ビルド中)
   - Deploying... (デプロイ中)
   - Ready (完了)

#### 4-6. デプロイURL確認

デプロイ完了後：

1. 「**Congratulations!**」画面が表示されます
2. 以下の形式のURLが発行されます：
   - `https://koji-recipe-app-xxxxx.vercel.app`
3. 「**Visit**」ボタンをクリックして動作確認
4. **このURLをコピーして控えてください**

### 開発者への共有事項

以下の情報を開発者に共有してください：

- ✅ **Vercel デプロイURL**（例: `https://koji-recipe-app-xxxxx.vercel.app`）

Vercelのデプロイが完了したら、Google OAuthの設定を更新する必要があります。

### お客様にご依頼すること

#### 5-1. Google Cloudコンソールで更新

1. https://console.cloud.google.com/ にアクセス
2. Step 3で作成したプロジェクト（`koji-recipe-oauth`）を選択
3. 左メニューの「**APIとサービス**」→「**認証情報**」をクリック
4. 「**OAuth 2.0 クライアント ID**」セクションで、作成した「**koji-recipe-supabase**」をクリック
5. 「**承認済みのリダイレクト URI**」セクションで「**+ URIを追加**」をクリック
6. 以下を追加：
   ```
   https://koji-recipe-app-xxxxx.vercel.app/auth/callback
   ```
   - ⚠️ **重要**: `xxxxx`の部分は、Step 4-6で取得した**実際のVercel URL**に置き換えてください
   - Supabaseのコールバック（既に設定済み）と**両方**必要です：
     - `https://xxxxx.supabase.co/auth/v1/callback` ← 既存
     - `https://koji-recipe-app-xxxxx.vercel.app/auth/callback` ← 新規追加
7. 「**保存**」ボタンをクリック

#### 5-2. 動作確認

1. Vercel URLにアクセス: `https://koji-recipe-app-xxxxx.vercel.app`
2. ログインページが表示されることを確認
3. 「**Googleでログイン**」ボタンをクリック
4. Google認証画面が表示されることを確認
5. ログインが成功してホーム画面に遷移することを確認

⚠️ **トラブルシューティング**: ログインできない場合は、本ガイド末尾の「よくある問題と解決方法」を参照してください。

## 🌐 Step 6: 独自ドメイン設定（任意）

独自ドメイン（例: `koji-recipe.com`）を使用する場合の手順です。

⚠️ **注意**: このステップは任意です。初期段階では、VercelのデフォルトURL（`xxxxx.vercel.app`）で問題ありません。

### お客様にご依頼すること

#### 6-1. ドメイン購入

1. ドメイン登録サービスでドメインを購入：
   - **お名前.com**: https://www.onamae.com/
   - **ムームードメイン**: https://muumuu-domain.com/
   - **Google Domains**: https://domains.google/
2. 希望のドメイン名を検索して購入（例: `koji-recipe.com`）
3. 費用: 約¥1,000〜2,000/年

#### 6-2. Vercelでドメイン設定

1. Vercelダッシュボード→プロジェクトを選択
2. 上部の「**Settings**」タブをクリック
3. 左メニューの「**Domains**」をクリック
4. 「**Add**」ボタンをクリック
5. 購入したドメインを入力（例: `koji-recipe.com`）
6. 「**Add**」をクリック
7. DNS設定の指示が表示されます：
   - **Type**: `CNAME`
   - **Name**: `@` または `www`
   - **Value**: `cname.vercel-dns.com`

#### 6-3. ドメインレジストラでDNS設定

1. ドメインを購入したサービス（お名前.com等）にログイン
2. DNS設定画面を開く
3. Vercelで表示された設定を追加：
   - CNAMEレコードを追加
   - ホスト名: `@` または空欄
   - 値: `cname.vercel-dns.com`
4. 設定を保存

⚠️ **注意**: DNS設定が反映されるまで、数分〜48時間かかる場合があります。

#### 6-4. Google OAuthのリダイレクトURI更新

独自ドメインを設定した場合、Google OAuthにもURLを追加：

1. Google Cloud Console → 認証情報
2. OAuth 2.0 クライアントID を編集
3. 「承認済みのリダイレクトURI」に追加：
   ```
   https://koji-recipe.com/auth/callback
   ```
4. 「保存」をクリック

## ❗ よくある問題と解決方法

### 問題1: Googleログインができない

**症状**: 「redirect_uri_mismatch」エラーが表示される

**原因**: Google CloudのリダイレクトURIが正しく設定されていない

**解決方法**:
1. Google Cloud Console → 認証情報 → OAuth 2.0 クライアントID
2. 「承認済みのリダイレクトURI」に以下が**両方**あることを確認：
   - `https://xxxxx.supabase.co/auth/v1/callback`
   - `https://xxxxx.vercel.app/auth/callback`
3. URLに**スペースや改行が入っていないか**確認
4. `http`ではなく`https`であることを確認
5. 保存後、5分ほど待ってから再試行

### 問題2: Vercelデプロイが失敗する

**症状**: 「Build failed」エラー

**原因**: 環境変数が設定されていない、またはコードにエラーがある

**解決方法**:
1. Vercel → プロジェクト → Settings → Environment Variables
2. 以下が正しく設定されているか確認：
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. 値に**スペースや改行が入っていないか**確認
4. 再デプロイ: Deployments → 最新デプロイの「...」→ Redeploy

### 問題3: アプリにアクセスできない

**症状**: 404 Not Found または画面が真っ白

**原因**: デプロイが完了していない、またはビルドエラー

**解決方法**:
1. Vercel → プロジェクト → Deployments
2. 最新のデプロイが「Ready」になっているか確認
3. エラーがある場合、ログを確認
4. 必要に応じて開発者に連絡

### 問題4: Supabaseプロジェクトが一時停止される

**症状**: 「Project paused」というメッセージが表示される

**原因**: 1週間以上アクセスがない（Free プランの制限）

**解決方法**:
1. Supabaseダッシュボードにアクセス
2. 該当プロジェクトの「Resume」ボタンをクリック
3. 数分で復帰します
4. 定期的にアクセスするか、Proプランへアップグレード

### 問題5: 環境変数が反映されない

**症状**: アプリでSupabase接続エラーが発生

**原因**: 環境変数設定後に再デプロイしていない

**解決方法**:
1. Vercel → Settings → Environment Variables で設定を確認
2. Deployments タブに移動
3. 最新デプロイの「...」→ 「Redeploy」をクリック
4. 環境変数は**再デプロイ後に反映**されます
