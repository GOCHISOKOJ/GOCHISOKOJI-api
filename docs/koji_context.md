## 各こうじの特徴（ユーザー提供情報）

### コンソメこうじ

- イタリアやフランス料理で使われる **ソフィット** と同じ原材料
- コンソメの代わりにも使える
- コンソメキューブと比べると **塩分濃度は半分以下**
- 置き換え目安
  - コンソメ大さじ1 → コンソメこうじ大さじ1
  - 水140cc + コンソメこうじ小さじ2 → スープ
- 使いどころ
  - オムライス / パスタ / グラタン / シチュー など、洋食の味付け・ベース

### 中華こうじ

- ジンジャーガーリックペーストのような調味料（パンチがある）
- ウェイパー / 中華だし / 鶏ガラ の代わりにも使える
- 各調味料と比べると **塩分濃度は半分以下**
- 使用方法・代用方法はコンソメこうじと同じ
- 使いどころ
  - 麻婆豆腐 / 唐揚げ / 野菜炒め など、中華風の味付け

### たまねぎこうじ

- 玉ねぎの甘みと旨みを引き出した、和にも洋にも使える調味料
- 飴色玉ねぎのようなコクがあり、これ一つで味がまとまる
- 「何を入れたらいいか迷ったとき」の味の土台になる
- 一般的な塩こうじよりも甘みと旨みがある
- 塩・うま味調味料・だし代わりとして使え、塩分は一般的な調味料より控えめ
- 使いどころ
  - 肉や魚の下味 / 炒め物 / スープ / 煮込み / ドレッシング など幅広い
